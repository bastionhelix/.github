# Reporting a security issue

If you think you've found a security problem in a Bastion Helix app, **please don't post it in public discussions.**

Email **support@bastionhelix.com** with the subject line **"Security"**, and include:
- which app and version (if you know it),
- what you found and how to reproduce it,
- what someone could do with it.

We'll acknowledge your report, keep you updated while we fix it, and credit you when the fix ships if you'd like. Please give us a reasonable time to fix the problem before telling anyone else about it.

## If something has already gone wrong

How we handle a security incident, including telling Atlassian within 24 hours and affected customers within 72 hours where possible, is set out in our [security incident response plan](INCIDENT_RESPONSE.md).
